Separate observed schema/sample differences, actual generated storage-model differences and generated-artifact hash differences. Use semantic names for manifest collection paths, preserving ordered keys. When a side is invalid or DTO-only, model comparison is unavailable, never equivalent by default. Invalid proposals retain diagnostic actions for reviewed keys/constraints, conflicting scalar kinds, endpoint membership/direction and unknown cardinality.

Review only writes JSON to the caller's output stream. Existing `scaffold` publication/overwrite protection is unchanged. A valid model difference is not a migration, a whole-database integrity check, a breaking-change classification or automatic deployment authorization. Keep future model-to-migration synthesis separate in FUT-17/FUT-18.

Repeated offline compilation adds deliberate review cost; it is outside runtime query paths. Full IDE interaction and large-schema incremental review remain separate investigations. The [review contract](../../tools/GRAPHBRIDGE_TOOL.md) documents JSON/exit semantics and the Movies example.
