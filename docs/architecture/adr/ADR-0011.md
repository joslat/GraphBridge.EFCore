## Hosted runner resource policy

The first Linux CI run passed restore/build/unit/policy checks but refused fixture startup: 6.79 GiB was available, below the local shared-machine startup requirement of 7 GiB. The local reserve protects a second developer agent; the fresh GitHub-hosted VM has no such shared workload.

CI therefore explicitly opts into a dedicated hosted policy, guarded by `GITHUB_ACTIONS=true` and `RUNNER_ENVIRONMENT=github-hosted`. It retains a 2 GiB reserve, 0.5 GiB headroom and 1.5 GiB fixture budget. Local and self-hosted execution retain the 5 GiB reserve. Ownership, one-container checks, resource inspection and bounded container limits remain active. This is a preflight policy, not continuous memory enforcement. See the [version/capability matrix](../../../tests/verification/VERSION_CAPABILITY_MATRIX.md) and execution evidence (maintainer-local record) for tested profiles and CI outcomes.
