# GraphRAG claims and their evidence

What the experimental GraphRAG toolkit's public pages claim, and the evidence for each. It is kept up to date as the toolkit and its pages change. A claim with no evidence is either rewritten, removed, or listed under [Not verified](#not-verified), as its page says.

The kinds of evidence:
- **Offline:** unit tests with fakes, no database and no model ([GraphBridge.GraphRag.Tests](../GraphBridge.GraphRag.Tests/GraphBridge.GraphRag.Tests.csproj));
- **Live:** integration tests on a disposable Neo4j, with stand-ins for the models ([GraphBridge.IntegrationTests](../GraphBridge.IntegrationTests/GraphBridge.IntegrationTests.csproj), the `GraphRag*` files);
- **Real model:** calls to `zai-org/GLM-5.3-Flash` and `BAAI/bge-m3` on Bitdeer, recorded from 25 to 29 October 2026 and replayed at zero calls by [GraphBridge.GraphRag.RealModelTests](../GraphBridge.GraphRag.RealModelTests/GraphBridge.GraphRag.RealModelTests.csproj). The whole-book cases run where the book has been fetched.

Live and real-model cases pass on Neo4j 2026.09.0 and, on 30 October, on 2026.10.1, every row included. The real-model replays were checked against the live endpoint the same day: sample 09's test passed with GLM-5.3-Flash and bge-m3, 27 real calls.

## Not verified

This list is the record; the pages don't repeat it at each point:
- **Where a chunk-grounded passage sits in its source.** An adopted chunk whose source file wasn't given, or didn't contain it, is cited by its own text: the quote is proven to be in the passage, not where the passage is in the source ([answers](../../docs/graphrag/ANSWERS.md#how-citations-are-checked)).
- **neo4j-graphrag's extracted things.** GraphBridge doesn't read the entities neo4j-graphrag's own pipeline extracts: they have no key, spans or run, and adoption covers documents and chunks. neo4j-graphrag does read what GraphBridge extracts in the entity shape (above) ([Interop](../../docs/graphrag/INTEROP.md#caveats)).
- **An agent's own wording.** An agent answers through the toolkit's tools, whose citations are checked; what the agent then writes in its own words is not. In the real-model run the agent also called `search_documents`, whose passages are evidence, not checked citations.
- **The full NASA releases.** The real-model run covers the excerpts shipped with sample 09; `fetch` downloads the whole releases, which haven't been run with a model.
- **Scale beyond what was measured.** The limits page measures up to 20,000 passages on one machine and one small database configuration; nothing over 50,000 passages has been run, and no throughput or latency is promised.
- **Other providers.** One provider has been run, Bitdeer, with a second model family (DeepSeek-V4.1-Flash) as a smoke run. That run's calls weren't recorded, so what [Use a real model](../../docs/graphrag/REAL_MODELS.md#what-has-been-run) reports of it can't be replayed. Other OpenAI-compatible endpoints are expected to work through the same client, but haven't been run.
- **An index that isn't online.** The health report names it, but no test provokes it.
- **The whole-book merge under replay.** It failed in 2 of about 43 replays with a concurrency error, deleting a quotation of the merged character, and not in the 24 since; the cause isn't known yet. It ships as a known limitation, stated in [maintain](../../docs/graphrag/MAINTAIN.md#merging-duplicates), [limits](../../docs/graphrag/LIMITS.md#not-claimed) and the CHANGELOG.
- **A failed merge's message naming the refused element, and a save whose commit outcome was lost.** The test's failure is an interceptor's, before any command, and no test loses a commit.
- **Text2Cypher's `query-failed` and its timeout.** No test gives a query the server plans as read-only that then fails or times out.
- **An encrypted PDF.** `pdf-unreadable` is tested with a file that isn't a PDF and with a damaged page.
- **Office formats other than Word,** and lists, tables and images in Word files: the recipe pins only markitdown's `docx` extra, and its Word files hold a heading and paragraphs.
- **The 50,000 things a class that suggestions read.** No test reaches it; the removal bound is tested with the bound lowered.
- **The samples' commands added on 29 October:** sample 07's PDF `ingest`, sample 08's `merge`, `merge apply` and `merge undo`, sample 09's `chat`, `graph`, `ask --export` and `serve <url>`, and `setup`'s refusal on a database with other migrations. They were run by hand on Neo4j 2026.09.0; no test runs them.
