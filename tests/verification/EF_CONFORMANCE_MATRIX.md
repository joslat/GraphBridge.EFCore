## Explicitly unsupported behavior

| Surface | Current behavior and evidence |
|---|---|
| Synchronous entity queries/saves | Live query test verifies synchronous enumeration rejection; [save implementation](../../src/GraphBridge.EntityFrameworkCore/Update/Neo4jDatabase.cs) explicitly throws for synchronous persistence (source evidence) |
| Joins, grouping, set operators, Distinct, entity/custom-comparer Contains, All, Sum/Average, noninteger or relationship Min/Max, Last, ElementAt, SelectMany, SkipWhile/TakeWhile | Explicit rejection in the [unsupported-method visitor](../../src/GraphBridge.EntityFrameworkCore/Query/Neo4jQueryableMethodTranslatingExpressionVisitor.Unsupported.cs); this source audit is not an individual live test of every method |
| Filtering/ordering/aggregating after paging, repeated Take, arbitrary predicates and lossy casts | [Unit translation tests](../GraphBridge.UnitTests/QueryTranslationTests.cs) and selected live cases verify rejection without client predicate execution |
| General Include, navigation predicates and traversals inside tracked LINQ | One direct native-reference Include is live verified. Broader Include shapes, association/identified-edge Include and navigation predicates reject; explicit endpoint/edge roots and native DTO/path queries remain alternatives |
| Models without keys or mappings; owned, complex or inherited models; invalid mapping identifiers | Binding/model validation rejects; [binding tests](../GraphBridge.UnitTests/NodeBindingTests.cs) cover representative failures |
| ReloadAsync / GetDatabaseValuesAsync | [Boundary tests](../GraphBridge.UnitTests/ProviderStateBoundaryTests.cs) verify projection rejection before transport and without tracker mutation |
| Arbitrary converter ordering/range or incompatible property comparisons | [Review regressions](../GraphBridge.UnitTests/ReviewQueryTests.cs) verify rejection; successful conversion alone does not prove operator equivalence |

Unsupported operators fail rather than silently evaluating predicates on the client. Future additions require their own source/API research, error paths and live acceptance before changing this matrix. Ordinary unopted test runs skip live fixtures and cannot close any live gate.
